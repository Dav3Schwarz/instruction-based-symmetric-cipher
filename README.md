# instruction-based-symmetric-cipher
A custom symmetric encryption algorithm implemented in Python. The cipher generates instruction-based keys composed of action/value pairs, with the key determining transformations applied to both plaintext and a substitution alphabet.

## IMPORTANT
This cipher is not proven to be secure and was merely created as an exercise.

## Features
- Symmetric encryption and decryption
- Instruction-based key generation
- Action/value key pairs
- Dynamic substitution alphabet
- Reversible transformations
